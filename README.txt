WINNIECARDHOUSE WEBSITE — QUICK START

Files:
- index.html: complete responsive website in one file.
- README.txt: these instructions.

BEFORE PUBLISHING
1. Open index.html in a text editor.
2. Replace every instance of REPLACE-WITH-YOUR-EMAIL@example.com with your real business email.
3. Replace “Add your service area” and “Add your expected response time”.
4. Review the proposed 25% commission and all consignment terms. It is labeled as a draft/example, not a confirmed policy.
5. Test the submission form. It opens an email draft and does not upload data to a server. The visitor must attach photos to the email if needed.

FREE HOSTING OPTIONS
- Netlify: create a free account and deploy by dragging the folder containing index.html into Netlify's manual deploy area.
- GitHub Pages: create a repository, upload index.html, then enable Pages in repository settings.
- Cloudflare Pages: create a Pages project and upload/deploy the static site.

IMPORTANT
This is a static website. The form uses a mailto link, so it requires the visitor to have an email app configured. For a form that collects submissions directly online, connect a form service or add a backend. Do not ask customers to ship cards until you have written terms, a documented intake process, and clear shipping/insurance arrangements.
